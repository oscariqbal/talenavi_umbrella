# Satria Wijaya Wedding Organizer

The Satria Wijaya Wedding Organizer landing page project utilizes the Next.js framework to expand market visibility and reach in the digital era.

---

## Key Features

- A responsive design that ensures the landing page looks great on all devices
- Showcasing the various services offered by the wedding organizer
- Highlighting the unique value proposition and brand identity of the wedding organizer
- Providing easy access to contact information for potential clients

---

## Tech Stacks

| Service       | Description         | Tech           |
| ------------- | ------------------- | -------        |
| Frontend      | User dashboard      | React, Next JS |
| Backend       | Database Main       | PHP, Laravel   |
| Database      | Data Store          | MySQL          |
